Свойства компонента

Описание

Чип — компактная метка-фильтр или выбранное значение, которое можно снять: применённые фильтры над таблицей, выбранные товары, теги. Чип всегда относится к чему-то выбранному пользователем; для статуса объекта используйте Status, для количества — Badge. Состав: текст, элемент слева (иконка или аватар) и элемент справа (крестик для снятия).

Варианты

Filled

Нейтральная кнопка имеет низкий визуальный вес и предназначена для второстепенных действий. Она часто используется в паре с другими типами кнопок (например, для действия «Отмена») или для опций, которые не требуют активного привлечения внимания. Старайтесь не использовать её как единственную кнопку в группе, если это не контекст навигации.

Outlined

Основная кнопка сообщает о высоком приоритете и предназначена для ключевых действий в интерфейсе. Не используйте более одной основной кнопки в одной области просмотра. Они выделяют самые важные действия (например, «Сохранить», «Опубликовать») и устанавливают чёткую визуальную иерархию.

Small (S)

Позитивная кнопка используется для действий среднего приоритета с благоприятным исходом. Она подходит для ситуаций, когда действие важно, но не является основным целевым действием страницы. Также может использоваться для позитивных альтернативных действий, чтобы отделить их от основного потока.

Element left / right

Предупреждающий вариант используется для действий, которые требуют осторожности, но не являются разрушительными. Оранжевый цвет привлекает внимание пользователя, сигнализируя о необходимости проверки перед продолжением (например, «Выйти из аккаунта», «Изменить статус»).

Disabled

Этот вариант предназначен для акцентирования внимания на разрушительных действиях или действиях с негативными последствиями (например, «Удалить», «Заблокировать»). Красный цвет служит сигналом опасности, заставляя пользователя задуматься перед нажатием. Используйте этот стиль экономно.

Примеры использования

С иконками

Элемент слева (иконка/аватар) — контекст значения, элемент справа (крестик) — снять выбор.

Опасные действия

Используйте стиль Negative для действий, которые необратимы.

Рекомендации

✓ Делайте

  • Используйте глаголы в названиях (Сохранить, Отправить).
  • Используйте одну Accent-кнопку на группу действий.
  • Соблюдайте отступы между кнопками (минимум 8px).

✕ Не делайте

  • Не используйте слишком длинные названия.
  • Не ставьте две Accent-кнопки рядом.
  • Не используйте кнопку для навигации, если это выглядит как ссылка.

Кнопки должны обеспечивать чёткую обратную связь. Ниже представлены реальные интерактивные примеры и демонстрации анимаций перехода между состояниями.

Интерактивная песочница

Try it yourself

Попробуйте навести курсор и нажать на кнопки ниже. Они реагируют на ваши действия, демонстрируя реальную скорость анимации и смену цветов.

Hover (Наведение)

Состояние Hover показывает, что элемент интерактивен. Плавный переход (transition) важен для ощущения качества интерфейса. Обычно длится 150-200ms.

  • Изменяется фон (становится темнее/светлее).
  • Курсор меняется на pointer.

Press / Active (Нажатие)

Момент клика. Даёт немедленную тактильную обратную связь. Переход в это состояние должен быть мгновенным или очень быстрым (50-100ms).

  • Цвет становится ещё более насыщенным.
  • Может меняться тень или масштаб (scale).

Focus (Фокус)

Визуальный маркер для навигации с клавиатуры (Tab). Никогда не убирайте outline без замены на другой стиль фокуса.
