Описание

Button — это фундаментальный компонент интерфейса, инициирующий действие. Кнопки сообщают пользователям, что произойдёт после нажатия, и направляют их через сценарии использования.

Варианты

Accent variant

Основная кнопка сообщает о высоком приоритете и предназначена для ключевых действий в интерфейсе. Не используйте более одной основной кнопки в одной области просмотра. Они выделяют самые важные действия (например, «Сохранить», «Опубликовать») и устанавливают чёткую визуальную иерархию.

Neutral variant

Нейтральная кнопка имеет низкий визуальный вес и предназначена для второстепенных действий. Она часто используется в паре с другими типами кнопок (например, для действия «Отмена») или для опций, которые не требуют активного привлечения внимания.

Positive variant

Позитивная кнопка используется для действий, означающих успех, добавление или подтверждение (например, «Добавить», «Подтвердить»). Зелёный цвет сигнализирует о благоприятном исходе.

Warning variant

Предупреждающий вариант используется для действий, которые требуют осторожности, но не являются разрушительными. Оранжевый цвет привлекает внимание, сигнализируя о необходимости проверки перед продолжением (например, «Выйти из аккаунта», «Изменить статус»).

Negative variant

Этот вариант предназначен для акцентирования внимания на разрушительных действиях или действиях с негативными последствиями (например, «Удалить», «Заблокировать»). Красный цвет служит сигналом опасности. Используйте этот стиль экономно.

Примеры использования

С иконками

Иконки усиливают смысл действия. Ставьте иконку слева для действий и справа для навигации.

Опасные действия

Используйте стиль Negative для действий, которые необратимы.

Рекомендации

✓ Делайте

  • Используйте глаголы в названиях (Сохранить, Отправить).
  • Используйте одну Accent-кнопку на группу действий.
  • Соблюдайте отступы между кнопками (минимум 8px).

✕ Не делайте

  • Не используйте слишком длинные названия.
  • Не ставьте две Accent-кнопки рядом.
  • Не используйте кнопку для навигации, если это выглядит как ссылка.

Поведение

Кнопки должны обеспечивать чёткую обратную связь. Ниже — реальные интерактивные примеры и демонстрации переходов между состояниями.

Интерактивная песочница

Попробуйте навести курсор и нажать на кнопки ниже. Они реагируют на ваши действия, демонстрируя реальную скорость анимации и смену цветов.

Hover (Наведение)

Состояние Hover показывает, что элемент интерактивен. Плавный переход (transition) важен для ощущения качества интерфейса. Обычно длится 150–200ms.

  • Изменяется фон (становится темнее/светлее).
  • Курсор меняется на pointer.

Press / Active (Нажатие)

Момент клика. Даёт немедленную тактильную обратную связь. Переход в это состояние должен быть мгновенным или очень быстрым (50–100ms).

  • Цвет становится ещё более насыщенным.
  • Может меняться тень или масштаб (scale).

Focus (Фокус)

Визуальный маркер для навигации с клавиатуры (Tab). Никогда не убирайте outline без замены на другой стиль фокуса.

Focus ring: outline 2px Accent/300 (#A8C9FF), offset 2px

Нажмите на кнопку, чтобы увидеть симуляцию загрузки. Состояние загрузки предотвращает повторную отправку формы и информирует пользователя о прогрессе.
