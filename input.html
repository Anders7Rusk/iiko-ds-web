iiko DS → Form field + Input

Input

Поле ввода. Внутренние элементы настраиваются отдельно внутри компонента. Размеры M (лейбл сверху) / S / XS (без лейбла). Состояния: default, hover, focus, error, disabled. Под полем — support text.
